Private key → public key on a toy elliptic curve

5Discussion

  • Meaningful for a one-way function: determinism and easy forward computation; hardness of inversion (ECDLP — a complexity property, not a statistical one); good dispersion of the points and no obvious linear correlation between k and the coordinates.
  • Specific to cryptographic hash functions: avalanche effect (1 flipped input bit changes ~50% of the output bits), fixed-size output for arbitrary-length input, collision and second-preimage resistance. Scalar multiplication does not offer these: (k+1)G = kG + G, so neighbouring outputs are linked by a simple algebraic step.
  • Visible algebraic structure: kG and (n−k)G share x and have opposite y, so every x appears in pairs. A hash has no such symmetry.
  • The toy group is tiny, so histograms are noisy and k falls in a few tries. Real security comes only from size (~2²⁵⁶ points).
