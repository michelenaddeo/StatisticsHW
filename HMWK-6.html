Statistical independence: contingency tables and the chi-square test

Do two categorical variables X and F carry information about each other? This page builds the contingency table of a dataset, works out what the table would look like if X and F were independent, and measures the distance between the two with the chi-square statistic.

What this page answers

  1. Build the contingency table and compute marginal and conditional frequencies — sections 2 and 3.
  2. Expected frequencies under independence, chi-square statistic and p-value — section 4.
  3. Recall the theory of independence — section 1, in short.
  4. Interpret the result, and separate association from causality — sections 5 and 7. Section 6 adds a simulation that shows what the test can and cannot detect.

1Independence in short

Definition. X and F are independent when P(X = x, F = f) = P(X = x)·P(F = f) for every pair of values: knowing X does not change the distribution of F. In a table, every row of conditional frequencies equals the marginal distribution of F.

Test. With observed counts O, row totals r, column totals c and n observations, independence predicts E = r·c/n in each cell. The statistic χ² = Σ (O − E)²/E measures the distance from that prediction; if independence holds it follows approximately a chi-square distribution with (R − 1)(C − 1) degrees of freedom (valid when E ≥ 5). The p-value is the probability of a χ² at least as large, and independence is rejected if it falls below α (for example 0.05). Cramér's V, from 0 to 1, measures how strong the association is.

2Choose a dataset

A dataset is a list of paired observations (x, f). The program finds the categories of each variable and counts the pairs in every combination. Pick an example, simulate data, or paste your own pairs.

The same computation in Python 
import numpy as np
from scipy.stats import chi2

pairs = [...]                                   # list of (x, f) observations
rows = sorted({x for x, _ in pairs}); cols = sorted({f for _, f in pairs})
O = np.array([[sum(p == (x, f) for p in pairs) for f in cols] for x in rows])
n, r, c = O.sum(), O.sum(1), O.sum(0)
E = np.outer(r, c) / n                          # expected counts under independence
stat = ((O - E) ** 2 / E).sum()                 # chi-square statistic
df = (len(rows) - 1) * (len(cols) - 1)
p = chi2.sf(stat, df)                           # p-value

X has three categories (A, B, C) and F two (Yes, No). The strength sets how much P(Yes) depends on X: 0.5 + 0.25·strength for A, 0.5 for B, 0.5 − 0.25·strength for C. Strength 0 is true independence. The same controls feed the dataset “Simulated data” in section 2.

  • With strength 0 the test rejects in about α of the repetitions (false alarms).
  • With strength above 0 the rejection rate is the power of the test: it grows with n and with strength, so a small real dependence may go unnoticed at n = 100 yet be highly significant at n = 5000.

7Association is not causation

  • What the test says. A rejected independence means that X and F are statistically dependent, not why.
  • Possible explanations. X influences F, F influences X, a third variable influences both (a confounder), or the sample is not representative. Hair and eye colour are linked through ancestry; on the Titanic, class is also tied to sex, age and access to lifeboats.
  • Causal claims need a randomised experiment, or an explicit control of confounders.
