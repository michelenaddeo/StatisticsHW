Exercise 1

Riemann and Lebesgue integration

Two ways of building an integral from slices. Riemann cuts the domain into intervals; Lebesgue cuts the range into levels and measures where the function takes each level.

1The two definitions

Riemann. Split [a, b] into N intervals and add f(ξi)·Δxi, with ξi a tag in each interval. f is Riemann integrable when lower and upper (Darboux) sums meet, whatever the tags: bounded and continuous almost everywhere.
Lebesgue. Split the range into levels yj ≤ f < yj+1 and add yj·μ({x : yj ≤ f(x) < yj+1}), where μ is the length (measure) of the preimage. It only needs the preimages to be measurable.

For every Riemann integrable function the two integrals coincide. In the numerical versions below, Riemann uses N tags; Lebesgue evaluates f at M points, counts how many fall in each of K levels (the measure of the preimage is the fraction of points), and averages the lower and upper level sums.

5Where the two approaches differ

  • Dirichlet (1 on rationals, 0 on irrationals). Every interval contains both kinds of points, so lower Darboux sums are 0 and upper sums are 1 for every N: the Riemann sum depends on the tags (1 with rational tags, 0 with random tags) and the Riemann integral does not exist. For Lebesgue, {f = 1} = ℚ ∩ [0, 1] is countable with measure 0, so ∫ f = 0. A grid of points is made of rationals, so "grid" sampling just repeats the Riemann sum; random points are irrational with probability 1, which is why Monte Carlo finds the right measure.
  • Thomae (1/q at p/q, 0 at irrationals). It is continuous at every irrational point, so it is Riemann integrable, and both approaches converge to 0. The convergence is slow: the upper sums need the few small denominators in each interval.
  • Step functions and 1/√x. A step function with two values is a simple function: two levels give the exact Lebesgue integral, while Riemann sums are exact only when the jump falls on a partition point. 1/√x is unbounded: the Riemann integral is improper (the left sum has to skip x = 0) and errors fall like N−1/2, while the Lebesgue levels have to reach large values.

6Conclusions

Same value. For Riemann integrable functions both methods converge to the same number: sin x → 2, x² → 1/3, |x − ½| → 1/4, sin x / x → 1.85194.
Accuracy. For smooth functions the midpoint rule is by far the best (error ∝ N−2); the left rule goes like N−1. Lebesgue sums with K = N levels converge roughly like N−1 but with a much larger constant (they are limited by the level width), and Monte Carlo only reaches N−1/2.
Cost. All methods need about N evaluations. Lebesgue also needs a binning step, so it is a bit slower for no gain on smooth functions.
Pathological cases. Lebesgue's approach handles functions that Riemann's cannot (Dirichlet) because it looks at the size of level sets, not at how the function behaves on intervals.

Exercise 2

Numerical computation of the normal CDF

Φ(x) = ∫ from −∞ to x of e−t²/2/√(2π) dt has no elementary closed form, so it is computed numerically. Six methods are compared for accuracy and speed.

1Why no elementary formula, and what erf does

Liouville's theorem. If f·eg (f, g rational) has an elementary antiderivative, it has the form h·eg with h rational. For e−x²/2 (f = 1, g = −x²/2), differentiating h·eg and matching eg requires h′ − x·h = 1.
If h is a polynomial of degree d ≥ 0, h′ − x·h has degree d + 1 ≥ 1 and cannot equal 1. If h has a pole of order k at a finite point c, h′ has a pole of order k + 1 and x·h only order k, so h′ − x·h still has a pole. No rational h exists: there is no elementary antiderivative (Liouville, 1830s; a general decision procedure is Risch's algorithm).
The error function. Define erf(z) = (2/√π) ∫0z e−t² dt. Then, exactly, Φ(x) = ½ (1 + erf(x/√2)). This is an exact analytic representation, but erf is just a name for the integral: it is a special function, not a finite combination of elementary ones, so to get a number we still need an algorithm (quadrature, series, continued fraction or rational approximation).

3Comparison with web references

Φ(k) for k = 1…6 comes from the probability P(|X| ≤ kσ) = erf(k/√2), Φ(k) = (1 + P)/2, with P to 12 digits as tabulated online (Wikipedia, 68–95–99.7 rule; MathWorld, 68-95-99.7 Rule). The 12-digit values agree with the C library erf to 4·10−13, which sets the floor of the errors in the “web” rows. Other rows use the C library erfc. Trapezoid error falls like n−2 and Simpson like n−4, until rounding errors take over. The alternating Maclaurin series needs more terms as |x| grows and also loses digits to cancellation: for x = 6 its error levels off near 4·10−11 however many terms are added.

5Conclusions

Exact but not elementary. erf gives Φ exactly as an analytic object, but no finite formula in elementary functions computes it (Liouville).
Quadrature. Simple and robust: Simpson with 100 intervals is already accurate to about 10−10, but costs hundreds of evaluations of e−t²/2 per call.
Series. The Maclaurin series of erf is fine near 0 but unstable for |x| ≳ 3. A series with positive terms near the centre plus a continued fraction in the tails reaches rounding-level accuracy.
Rational approximations. The Hart/West algorithm is as fast as the cheapest formula here and accurate to rounding. The classic Abramowitz–Stegun formula is cheap but limited to about 10−7, with poor relative accuracy in the tails.
