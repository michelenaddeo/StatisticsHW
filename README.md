# Statistics HW

Interactive assignments for a statistics course, built around security and
cryptography topics. Each one is a single self-contained HTML page: plain
JavaScript and inline SVG charts, no external libraries.

| # | Topic |
|---|-------|
| 1 | Private key to public key on a toy elliptic curve: scalar multiplication, the discrete logarithm problem, statistical analysis of the output |
| 2 | From wallet seed to Ethereum address: BIP-39, BIP-32, secp256k1, Keccak-256, EIP-55 checksum and the avalanche effect |
| 2A | ... |
| 3 | Aggregate penetration scores: law of large numbers and central limit theorem, with live simulations |
| 4 | ... |
| 5 | ... |

To try one, download the file and open it in a browser.
